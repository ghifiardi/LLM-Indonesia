✨ Deck Studio

PowerPoint

Ubah brief/teks di atas menjadi deck PowerPoint yang tertata dan berdesain.

Tip: pilih Bebas / custom untuk mengikuti style guide di bawah. Jumlah slide bisa 3–30 agar topik besar tidak dipaksa terlalu padat.

Sumber deck otomatis: gambar yang diunggah → teks di kotak atas → slide yang terpilih.

Untuk PDF/DOCX/PPTX, jalankan companion lokal: npm run doc-server. TXT/MD/CSV bisa dibaca langsung.

Satu klik: Tantular membaca sumber, menyusun rencana, lalu menyisipkan slide langsung ke presentasi aktif agar hasil terlihat cepat. Di luar PowerPoint (atau jika sisip tidak didukung), file .pptx otomatis diunduh. Tombol Download .pptx selalu tersedia.
