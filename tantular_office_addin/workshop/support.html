Dukungan Workshop Tantular

Rilis ini ditujukan untuk workshop Microsoft 365 terfasilitasi di Mac dan Windows.

Spesifikasi laptop & ekspektasi

  • RAM 16 GB ke atas: pengalaman penuh dengan model 8B.
  • RAM 8 GB: otomatis memakai model ringan (lite, 4B) — tetap berfungsi, kualitas deck sedikit di bawah 8B.
  • Installer mendeteksi RAM secara otomatis dan memilih model yang tepat; tidak perlu diatur manual.
  • Model Tantular dipublikasikan di ollama.com/ghifidanukusumo/Tantular dan diunduh otomatis oleh installer (±5 GB untuk 8B, ±2,5 GB untuk lite) — sebaiknya jalankan installer dari rumah sebelum hari workshop.

Komponen lokal yang dibutuhkan

  • Microsoft 365 Word, Excel, atau PowerPoint (Mac atau Windows).
  • Node.js 18 atau lebih baru — unduh di nodejs.org.
  • Ollama — unduh di ollama.com — beserta model Tantular untuk workshop.
  • Sertifikat HTTPS lokal tepercaya yang dipasang oleh installer workshop.
  • Tantular Companion berjalan di https://localhost:3000.

Langkah demi langkah (ringkas)

  1. Jalankan satu perintah instalasi sesuai sistem operasi (bagian berikutnya). Node.js, Ollama, sertifikat, dan model Tantular (dari ollama.com, sesuai RAM) dipasang otomatis.
  2. Jalankan start-tantular-companion (.command di Mac / .bat di Windows) dan biarkan jendela terminalnya tetap terbuka.
  3. Tutup Office sepenuhnya (Cmd+Q di Mac), buka kembali, lalu pilih Home → Tantular → Open Tantular.
  4. Di pengaturan Tantular klik Refresh lalu Tes model terpilih — harus membalas dalam hitungan detik (panggilan pertama bisa lebih lama karena model baru dimuat).
  5. Klik Buat Deck / fitur Studio lainnya sekali, lalu tunggu spinner selesai. Klik berulang tidak mempercepat — justru menambah antrean dan memperlambat.

Kompatibilitas versi Office

Tantular berjalan di Microsoft 365 (langganan), Office di web, dan Office perpetual 2021/2024 (Mac & Windows). Office 2019 Mac kemungkinan berfungsi; Office 2019/2016 Windows tidak didukung (webview lama tanpa dukungan ES modules — pane akan blank; gunakan Word di web di mesin tersebut). Checklist verifikasi lengkap per mesin tersedia di file docs/OFFICE_PERPETUAL_COMPAT.md dalam paket workshop.

Instalasi satu perintah (paling mudah)

Salin satu baris sesuai sistem operasi, tempel, lalu Enter. Semua kebutuhan (termasuk Node.js dan Ollama bila belum ada) dipasang otomatis.

Mac — buka aplikasi Terminal, lalu jalankan:

curl -fsSL https://workshop-web-gamma.vercel.app/downloads/setup.sh | bash

Windows — buka PowerShell, lalu jalankan:

irm https://workshop-web-gamma.vercel.app/downloads/setup.ps1 | iex

Unduhan manual (alternatif)

  • Manifest workshop Microsoft 365
  • Paket instalasi Tantular Companion (Mac & Windows)

Instalasi per platform

  • Mac: jalankan install-tantular-workshop.command, lalu start-tantular-companion.command. Jika diblokir macOS, klik kanan → Open.
  • Windows: jalankan install-tantular-workshop.bat, lalu start-tantular-companion.bat. Jika Node.js/Ollama belum terpasang, installer menawarkan pemasangan otomatis lewat winget (setelahnya, jalankan installer sekali lagi). Jika pendaftaran manifest otomatis gagal, gunakan Word di web (office.com): Insert → Add-ins → Upload My Add-in dan pilih file manifest.

Membuka Tantular

Setelah manifest terpasang dan Office ditutup penuh (Cmd+Q di Mac, tutup semua jendela di Windows) lalu dibuka kembali, buka sebuah file Office dan pilih Home → Tantular → Open Tantular.

Pemeriksaan umum

  1. Pastikan Ollama sedang berjalan.
  2. Pastikan jendela terminal Tantular Companion tetap terbuka.
  3. Buka https://localhost:3000/src/taskpane.html satu kali dan setujui/percayai sertifikatnya bila diminta.
  4. Di pengaturan Tantular, klik Refresh lalu Tes model terpilih.
  5. Jika Buat Deck selalu gagal dengan pesan "Permintaan model lokal terlalu lama": RAM komputer kemungkinan tidak cukup untuk model 8B. Jalankan ollama pull ghifidanukusumo/tantular:lite, lalu di Pengaturan model lokal isi kolom Model Studio dengan ghifidanukusumo/tantular:lite dan klik Simpan. Jangan klik Buat Deck berulang kali saat menunggu — antrean permintaan membuat model makin lambat.

Untuk bantuan khusus workshop, hubungi fasilitator yang membagikan paket ini.
