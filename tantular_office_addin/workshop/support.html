Dukungan Workshop Tantular

Rilis ini ditujukan untuk workshop Microsoft 365 terfasilitasi di Mac dan Windows.

Spesifikasi laptop & ekspektasi

Tantular Office adalah profil yang berjalan di atas model dasar Qwen3.5 (9B atau 4B, sesuai RAM). Yang Anda pilih di panel adalah tantular-office:0.5-9b.

Sejak Agustus 2026 installer mengunduh profil jadi dari ollama.com, bukan menyusunnya di komputer Anda. Profil itu memakai presisi Q8 yang kualitasnya setara bobot penuh; versi Q4 sebelumnya gagal pada uji bahasa Indonesia kami (37 dari 40, ambang 38). Satu unduhan, tanpa langkah build.

  • RAM 16 GB ke atas: pengalaman penuh dengan model 9B (unduhan ±10 GB).
  • RAM di bawah 16 GB: otomatis memakai model ringan 4B (±3,4 GB) — tetap berfungsi, kualitas deck sedikit di bawah 9B.
  • Batas ini naik dari 12 GB ke 16 GB karena model 9B kini berukuran 10 GB, bukan 6,6 GB. Komputer 12 GB akan tersendat bila dipaksa memakai 9B.
  • Installer mendeteksi RAM secara otomatis dan memilih model yang tepat; tidak perlu diatur manual.
  • Unduhannya besar — jalankan installer dari rumah sebelum hari workshop, jangan mengandalkan Wi-Fi ruangan.

Komponen lokal yang dibutuhkan

  • Microsoft 365 Word, Excel, atau PowerPoint (Mac atau Windows).
  • Node.js 18 atau lebih baru — unduh di nodejs.org.
  • Ollama — unduh di ollama.com — beserta model Tantular untuk workshop.
  • Sertifikat HTTPS lokal tepercaya yang dipasang oleh installer workshop.
  • Tantular Companion berjalan di https://localhost:3000.

Baru: OCR Apple Vision (Mac), desain deck baru, batas file 100 MB

  • Batas unggah dokumen naik ke 100 MB (sebelumnya 35 MB).
  • 6 gaya desain deck baru di dropdown "Gaya desain" Deck Studio: Nusantara, Monokrom, Samudra, Terang, Tegas, Akademik (plus "Bebas / custom").
  • Mac: ekstraksi teks dari gambar kini memakai Apple Vision OCR (lebih akurat untuk teks Indonesia). Windows tetap memakai model vision lokal seperti biasa.

Sudah pernah memasang sebelumnya? Ini yang perlu diperbarui

  • Panel Tantular (gaya desain baru): otomatis, tanpa unduh ulang. Cukup tutup Office sepenuhnya (Cmd+Q di Mac), buka kembali, lalu pastikan tag build di header panel menunjukkan b0814a atau lebih baru. Masih tag lama? Tutup penuh Office sekali lagi.
  • Batas 100 MB dan OCR Apple Vision: perlu paket Companion terbaru. Paket lama belum memuat komponen barunya. Jalankan ulang perintah instalasi satu baris di bawah (bagian "Instalasi satu perintah") — paket terbaru akan terunduh otomatis, pengaturan Anda tidak hilang.
  • Khusus Mac, setelah unduh ulang: di folder paket jalankan npm run doc-setup satu kali (perlu Python 3). Companion menjalankannya sendiri setelah itu — tidak perlu perintah doc-server terpisah. Saat ekstraksi gambar, baris status akan menampilkan "Apple Vision".
  • Windows: cukup unduh ulang paket untuk batas 100 MB; OCR tetap memakai model vision lokal (tidak ada langkah tambahan).

Langkah demi langkah (ringkas)

  1. Jalankan satu perintah instalasi sesuai sistem operasi (bagian berikutnya). Node.js, Ollama, sertifikat, dan model Tantular (dari ollama.com, sesuai RAM) dipasang otomatis.
  2. Jalankan start-tantular-companion (.command di Mac / .bat di Windows) dan biarkan jendela terminalnya tetap terbuka.
  3. Tutup Office sepenuhnya (Cmd+Q di Mac), buka kembali, lalu pilih Home → Tantular → Open Tantular.
  4. Di pengaturan Tantular klik Refresh lalu Tes model terpilih — harus membalas dalam hitungan detik (panggilan pertama bisa lebih lama karena model baru dimuat).
  5. Klik Buat Deck / fitur Studio lainnya sekali, lalu tunggu spinner selesai. Klik berulang tidak mempercepat — justru menambah antrean dan memperlambat.

Kompatibilitas versi Office

Teruji: Microsoft 365 (langganan) di Mac & Windows, dan Office di web. Dirancang kompatibel (belum diverifikasi di perangkat nyata): Office perpetual 2021/2024 — Tantular memakai API dasar (WordApi 1.1) dengan fallback otomatis, jadi secara teknis seharusnya berjalan; jika Anda memakai Office 2021/2024, bantu kami dengan menjalankan checklist di docs/OFFICE_PERPETUAL_COMPAT.md (ada dalam paket workshop) dan laporkan hasilnya ke fasilitator. Tidak didukung: Office 2019/2016 Windows (webview lama — pane akan blank; gunakan Word di web di mesin tersebut).

Persiapan sebelum workshop (preflight)

Kirim versi Office Anda ke panitia beberapa hari sebelum acara: buka Word → File → Account (Windows) atau Word → About Word (Mac), foto/salin versi yang tertera. Ini mencegah kejutan kompatibilitas di hari-H.

Windows dengan Office 2021: pastikan Microsoft Edge WebView2 Runtime terpasang (unduhan kecil dari situs Microsoft; sudah bawaan di Windows 11 dan Microsoft 365 terbaru). Tanpa WebView2, panel Tantular dapat tampil kosong — kini panel akan menampilkan pesan "Versi Office tidak didukung" alih-alih layar putih.

Instalasi satu perintah (paling mudah)

Salin satu baris sesuai sistem operasi, tempel, lalu Enter. Semua kebutuhan (termasuk Node.js dan Ollama bila belum ada) dipasang otomatis.

Mac — buka aplikasi Terminal, lalu jalankan:

curl -fsSL https://office.tantular.ai/downloads/setup.sh | bash

Windows — buka PowerShell, lalu jalankan:

irm https://office.tantular.ai/downloads/setup.ps1 | iex

Unduhan manual (alternatif)

  • Manifest workshop Microsoft 365
  • Paket instalasi Tantular Companion (Mac & Windows)

Instalasi per platform

  • Mac: jalankan install-tantular-workshop.command, lalu start-tantular-companion.command. Jika diblokir macOS, klik kanan → Open.
  • Windows: jalankan install-tantular-workshop.bat, lalu start-tantular-companion.bat. Jika Node.js/Ollama belum terpasang, installer menawarkan pemasangan otomatis lewat winget (setelahnya, jalankan installer sekali lagi). Jika pendaftaran manifest otomatis gagal, gunakan Word di web (office.com): Insert → Add-ins → Upload My Add-in dan pilih file manifest.

Membuka Tantular

Setelah manifest terpasang dan Office ditutup penuh (Cmd+Q di Mac, tutup semua jendela di Windows) lalu dibuka kembali, buka sebuah file Office dan pilih Home → Tantular → Open Tantular.

Pemeriksaan umum

Mulai dari sini: di folder paket jalankan npm run doctor. Satu perintah ini memeriksa sertifikat, Companion, Ollama, model, dan manifest sekaligus, lalu menyebutkan perintah perbaikan untuk apa pun yang bermasalah. Dua baris pertamanya menampilkan versi paket Anda — sertakan itu bila melaporkan masalah, karena dua unduhan bisa punya nama berkas sama tetapi isi berbeda.

Bila ingin memeriksa manual:

  1. Pastikan Ollama sedang berjalan.
  2. Pastikan jendela terminal Tantular Companion tetap terbuka.
  3. Buka https://localhost:3000/src/taskpane.html satu kali dan setujui/percayai sertifikatnya bila diminta.
  4. Di pengaturan Tantular, klik Refresh lalu Tes model terpilih.
  5. Saat panel sedang bekerja, ia menampilkan waktu berjalan dan tombol Batal. Bila terasa lama, tekan Batal — jangan mengklik tombolnya berulang kali, karena setiap klik menambah antrean dan justru memperlambat model.
  6. Jika Buat Deck selalu gagal dengan pesan "Permintaan model lokal terlalu lama": RAM komputer kemungkinan tidak cukup untuk model 9B. Jalankan ulang installer agar memilih model 4B, lalu di Pengaturan model lokal isi kolom Model Studio dengan tantular-office:lite dan klik Simpan.

Untuk bantuan khusus workshop, hubungi fasilitator yang membagikan paket ini.
