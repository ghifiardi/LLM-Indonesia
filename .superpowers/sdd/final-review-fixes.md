Security fix: static file handler in tantular_office_addin/tools/dev-server.mjs served every file under the served root (including data/workspace.json and certs/localhost.key) with Access-Control-Allow-Origin: * — any web page could fetch the workspace store or TLS private key, bypassing the /api/workspace origin allowlist. Fix: hard-block requests whose resolved path's first segment is data/ or certs/, returning 404 (not 403, to avoid confirming existence), applied before any fs.readFile — existing path-traversal check (filePath.startsWith(root)) left intact. Added tantular_office_addin/.gitignore (data/, certs/) — neither directory was previously tracked in git (git ls-files data/ and git ls-files certs/ both empty), so nothing needed untracking. New test tests/devServerStatic.test.mjs spawns the real dev-server.mjs as a child process on a free port and verifies: GET /data/workspace.json -> 404, GET /certs/localhost.key -> 404, a path-traversal-flavored /./data/workspace.json -> 404, GET /src/taskpane.html -> 200 (normal static asset unaffected), GET /api/workspace with no Origin header -> 200 (API allowlist behavior unchanged). 155 tests total, 155 pass, 0 fail (154 pre-existing + 1 new test file covering the above 5 assertions).
